# Kiai API

Kiai provides a **public API** for developers to extend the functionality of the bot.

> To get an API key, join our support server and ask a developer.

---

## API Endpoints

The full list of endpoints is available here:  
[https://api.kiai.app/v2/docs](https://api.kiai.app/v2/docs)

---

## Authentication

Authentication works via **Applications**, similar to Discord bot applications.  
You need to **authorize** an application to each server with a set of permissions using the `/application` command.

---

## Permissions

Permissions determine what actions an application can perform.  
They are granted during authorization and can be changed later by reauthorizing the application via `/application`.  

Permissions are stored as a **variable-length integer** and calculated using **bitwise operations**.

### List of Permissions

| Permission Name | Description                          | Value              |
| --------------- | ------------------------------------ | ----------------- |
| Levels          | View and edit all levels and XP      | 0x00001 (1 << 0) |
| Multipliers     | View and edit multipliers            | 0x00010 (1 << 1) |
| Export          | Export data from your guild          | 0x00100 (1 << 2) |
| Denylist        | View and edit the server's denylist  | 0x01000 (1 << 3) |
| Rewards         | View and edit the server's rewards   | 0x10000 (1 << 4) |

---

## Rate Limits

Every application has a **60 requests per minute** rate limit.  
Exceeding this will temporarily block API access.  

> Rate limits can be increased for legitimate use cases—contact support if needed.

---

## Obtaining a Token

To obtain a token for your application, join our [support server](https://discord.gg/6mw5BRYfs) and open a support post.

You will need to provide:  
- A **unique ID** (typically your bot's ID)  
- An **application name**
