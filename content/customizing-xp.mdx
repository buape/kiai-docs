# Customizing XP Gain

Kiai allows you to customize exactly how members earn XP in your server. You can adjust message XP, formulas, level caps, and reset behavior.

---

## Message XP

Message XP is awarded for chat activity. It is calculated randomly within your configured range and does not depend on message length.

Settings can be found in `/settings > Message XP`.

- **XP Cooldown**: The time a member must wait before another message can grant XP.  
- **Minimum XP per Message**: The smallest amount of XP a message can award.  
- **Maximum XP per Message**: The largest amount of XP a message can award.  
- **Level Cap**: The maximum level a member can reach. Members continue earning XP beyond this level, but it will not display above the cap.  
- **Reset Member XP on Leave/Kick**: If enabled, a member’s XP is reset when they leave the server or are kicked.  
- **Reset Member XP on Ban**: If enabled, a member’s XP is reset when they are banned from the server.

**Example:**  
If Minimum XP is 5, Maximum XP is 15, and Cooldown is 60 seconds:  
- A member sends a message and randomly receives between 5 and 15 XP.  
- They must wait 60 seconds before their next message can grant XP.

---

## XP Formula

The XP Formula determines how much XP is needed to reach each level.

- **Default formula**:  
```
12 * ({level} * {level}) + {level} * 12
```
You can visualize this formula here: [XP Visualizer](https://go.kiai.app/visualizer)

- `{level}` represents the member's current level and is required in custom formulas.  
- Kiai does not support restarting XP at 0 for each level. To achieve a similar effect, add `+ {xp}` to your formula.

**Example:**  
Custom formula:  
```
15 * ({level} * {level}) + {level} * 10 + {xp}
```
- `{level}` calculates the base XP needed for the next level.  
- `{xp}` ensures XP is cumulative across levels.

This allows precise control over leveling speed and progression curves.

---

By customizing XP gain and formulas, you can create unique progression experiences tailored to your server.
