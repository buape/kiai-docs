# Welcome to Kiai

Thank you for choosing **Kiai**, the Discord leveling and progression bot created by **Buape Studios**.  
This documentation will help you understand what Kiai does, how to set it up, and how to use its features effectively in your server.

Whether you're a server owner configuring your first leveling system or a user exploring what Kiai can do, this guide serves as a reliable starting point.

In these docs, you’ll find:

- Advanced configuration and optional integrations
