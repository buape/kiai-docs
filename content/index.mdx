# Welcome to Kiai

Thank you for choosing **Kiai**, the Discord leveling and progression bot created by **Buape Studios**.
This documentation explains what Kiai does, how to set it up, and how to use its features in your server.

Whether you are a server owner configuring your first leveling system, or a member exploring what Kiai can do, this guide is a reliable starting point.

---

## What You Can Expect

In these docs, you will find:

- An overview of how Kiai works
- Setup instructions and core concepts
- Command references and feature guides
- Customization options for XP, rank cards, rewards, and more
- Advanced configuration and optional integrations

If you are new, read **What Is Kiai** next.
