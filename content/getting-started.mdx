# Getting Started with Kiai

## Add Kiai to your Server
Go to kiai.app and click the [Add to Discord](https://go.buape.com/invite-kiai) link

From there Discord will ask you what server and with what permissions you would like to add Kiai to. It is recommended that you leave the invite permissions on the default.

If you change any of the permissions, some features may not work until the relevant permissions are given to the bot.

## Confirm Kiai can Respond

You can verify that the bot was successfully added to the server by running a command like `/ping` or `/rank` and ensuring that the bot replies successfully.

## Configure Kiai Settings

It is now the time to customize Kiai to meet your servers needs. It is recommended to start with your leveling settings like your Leveling Formula, cooldown, min/max, and more. For more infomation on customizing [XP Settings](customizing-xp.mdx), [Voice XP Settings](voice-xp.mdx), [Multipliers](multipliers.mdx), and more see their respective documentation pages.

### Importing Data

If you're migrating from another bot, you can import your data by using the /import command at this step.

## Configure Leveling Rewards

After getting Kiai all configured with the settings you desire, now you can set up all the leveling rewards that you like. Kiai offers many options when it comes to leveling rewards that can be learned more about on the [Leveling Rewards Page](introduction-to-rewards.mdx).
