# Getting Started with Kiai

Follow these steps to set up Kiai in your server.

## 1. Add Kiai to Your Server

1. Go to [kiai.app](https://kiai.app).
2. Click [Add to Discord](https://go.buape.com/invite-kiai).
3. Select your server.
4. Keep the default permissions, unless you have a reason to change them.

If you change the default permissions, some features may not work until you grant the missing permissions.

---

## 2. Confirm Kiai Can Respond

Run a command, such as `/ping` or `/rank`, and confirm that Kiai replies.

---

## 3. Configure Kiai's Settings

Start with your leveling settings, such as the leveling formula, cooldown, and minimum and maximum XP. For more information, see [Customizing XP](customizing-xp.mdx), [Voice XP](voice-xp.mdx), and [Multipliers](multipliers.mdx).

### Import Existing Data

If you migrate from another bot, use the `/import` command to bring over your data. Kiai imports from MEE6, AmariBot, Lurkr, CakeyBot, Tatsu, Gaius Play, Polaris, Discortics, LevelUp, Piggy, and its own `/export` files. Lurkr, CakeyBot, Polaris, LevelUp, and Kiai need a file upload from the source bot. Tatsu needs an API key from your Tatsu account, entered in the `api-key` option.

Before you can import, your server's leveling data must be empty. Run `/reset` to clear it, then run `/import` within 5 minutes. Importing replaces the data types you select. It does not merge with existing data.

> If you import "Other Settings" from LevelUp, Kiai also unlocks `/auto-leaderboard create` for your server for free, without needing Server Premium.

---

## 4. Set Up Leveling Rewards

After you configure your settings, set up leveling rewards for your server. For more information, see the [Leveling Rewards](introduction-to-rewards.mdx) page.
