# Leaderboards

## Regular Leaderboards

Leaderboards are a great way to visualize activity among members over a time period or of all time. Leaderboards can be viewed by running the `/leaderboard` command.

Leaderboards can track the following metrics:  
- XP and Levels  
- Messages Sent  
- Voice Minutes  
- XP Streaks  

Additional options include:  
- **Time:** Set the time period the leaderboard covers

This type of leaderboard will not update unless the command is ran again and a new leaderboard is generated.

## Automatically Updating Leaderboards

Kiai offers **automatically updating leaderboards**, which can be created using `/auto-leaderboard create`.  

Automatically updating leaderboards can also be given a description which will add a custom description for the leaderboard display.  

> Note: Some leaderboard features are **premium-only**.
