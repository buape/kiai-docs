# Voice XP

**Required Permissions:**
Kiai needs the **`View Channel`** and **`Connect`** permissions in a voice channel for this feature to work there.

Configure Voice XP in `/settings > Voice XP`.

Voice XP lets members earn XP by spending time in voice channels.

- **Voice XP**: Turns the feature on or off.
- **Voice XP per Minute**: How much XP a member earns for each minute in a voice channel.
- **Minimum Users Required to Gain XP**: The minimum number of members a voice channel needs before anyone in it earns XP. Set between 1 and 100. Muted and deafened members still count toward this minimum. They just do not personally earn XP themselves.

### How Voice XP Works

- Kiai checks every voice channel every 30 seconds and awards half of the per-minute XP rate to each eligible member, rounded down.
- A voice channel must meet the minimum user count before anyone in it earns XP.
- A member earns XP only while unmuted and undeafened.
- A denylisted member does not earn Voice XP. See [Denylists](denylists.mdx).
- Any [multiplier](multipliers.mdx) for the member's roles, the channel, or the server applies to Voice XP.
