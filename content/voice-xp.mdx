# Voice XP

**Required Permissions:**  
Kiai must have **`View Channel`** and **`Connect`** permissions for the voice channel for this feature to work.

Voice XP settings can be found in `/settings > Voice XP`.

Kiai’s **Voice XP** feature allows members to earn XP by participating in voice channels.  

### How Voice XP Works

- A voice channel must meet the **minimum user count** configured in the settings to start awarding XP.  
- Users only earn XP for **time spent unmuted and undeafened** in the voice channel.  
- XP is awarded every 30 seconds while a user is in the channel.

This encourages active participation in voice chats while preventing passive XP farming.
