# Rewards
    
Kiai offers **rewards** as a way to give members something special when they reach a certain level.

Currently, there are five reward types:  
- Roles  
- Custom Messages  
- Money (via UnbelievaBoat Currency)  
- Nickname  
- Leaderboard Roles  

---

## Roles

**Required Permissions:**  
Kiai needs the **`Manage Roles`** permission to apply role rewards.

Role rewards can **give or remove a role** when a user reaches a specified level:  
- **Giving roles:** Commonly used for level roles (e.g., Level 10, Level 20).  
- **Removing roles:** Often used to remove roles that were applied on join or grant temporary permissions.  

Optional parameters include:  
- **Required role:** The user must have a certain role to receive the reward.  
- **Temporary length:** Grants the reward for a limited time.

---

## Custom Messages

Custom Messages allow Kiai to send a message **separate from the level-up message** when a user reaches the reward level.  

Settings include:  
- **Channel:** The channel the message will be sent in (configured via `/rewards add message`).  
- **Required role:** Optional requirement for a user to receive the reward.

---

## Money

Kiai can integrate with **UnbelievaBoat** to reward member with currency when reaching a specified level.  

For more details, see the **UnbelievaBoat Integration** guide.

---

## Nicknames

Nicknames can be applied when a user reaches a specific level.  

**Example:** Add an emoji to a user’s name at Level 10.  

> Tip: Use this for **one-off cases**. If you want a consistent nickname format for all users, use the **Nickname Format** feature instead.
