# Placeholders

Kiai provides a set of **placeholders** that you can use in several places, such as:
- Level-up messages
- XP Streak messages
- XP Drop messages
- Custom Message rewards
- Nickname rewards and the Nickname Format setting

Not every placeholder works in every location, since some locations do not have the data a placeholder needs. If you use an unsupported placeholder, it appears as plain text in the message instead of being replaced.

---

## Where Each Placeholder Works

| Location | Supported placeholders |
| --- | --- |
| Level-up message | `{guild.*}`, `{user.*}`, `{level}`, `{level.new}`, `{level.old}`, `{prestige}`, `{rewards.*}` |
| XP Streak message | `{guild.*}`, `{user.*}`, `{streak}`, `{bonus}` |
| XP Drop message | `{guild.*}`, `{xp}`, `{expire}` |
| Custom Message reward | `{guild.*}`, `{user.*}`, `{level}`, `{level.new}`, `{level.old}` |
| Nickname reward / Nickname Format | `{guild.*}`, `{user.*}`, `{level}`, `{level.new}`, `{level.old}` |

`{streak}` and `{bonus}` only work in XP Streak messages. `{expire}` only works in XP Drop messages. Webhook rewards do not support placeholders.
