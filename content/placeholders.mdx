# Placeholders

Kiai provides a set of **placeholders** that can be used in various locations, such as:  
- Level Up messages  
- XP Streak messages  
- XP Drops  

Not all placeholders are supported everywhere. If a placeholder is used in an unsupported location, it will display as-is in the message.
